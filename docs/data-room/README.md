## What a buyer receives in a sale

1. **The App Store listing** (Apple ID 6764209094), with its ratings, reviews and
   update channel, via Apple's app transfer.
2. **The repository** `HOboGoblin45/frontier-go`: the app, the native player,
   the ingest pipeline, the catalog, the website, CI, and this folder.
3. **The website**, which is GitHub Pages built from that repository, so it moves
   with it. A custom domain, if one is bought, transfers at the registrar.
4. **No user database.** There is none. The app collects no data, so there is
   nothing to migrate, disclose or secure. That is a feature to sell, not a gap.
