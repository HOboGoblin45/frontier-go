# scripts/

Windows PowerShell helpers for setup and release, plus two small build
utilities. See `SCRIPTS-OVERVIEW.md` for what each one does and the one-time
list.

`build-ios.sh`, `screenshot.sh` and `render-svg.mjs` are Unix helpers used by CI
and by the icon pipeline.

Scripts that tested the old YouTube embed proxy and captured Trailer Roulette's
App Store screenshots have moved to `docs/archive/trailer-roulette/scripts/`.
